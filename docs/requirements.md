# LMS Requirements and MVP Plan

## Core roles
- Admin / Principal
- Teacher
- Student
- Parent

## MVP features
1. Authentication and role-based access
2. School setup with classes and sections
3. Student and teacher management
4. Courses, lessons, and assignments
5. Attendance and results
6. Announcements and parent communication

## Local and regional needs
- Urdu and English UI support
- WhatsApp or SMS notifications
- Mobile-first interface for low bandwidth
- Simple onboarding for non-technical school staff

## Suggested roadmap
- Phase 1: MVP foundation and dashboard
- Phase 2: Attendance, exams, and results
- Phase 3: Messaging and notifications
- Phase 4: Mobile app and reporting
