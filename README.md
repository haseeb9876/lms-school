# School LMS MVP

This starter project lays the foundation for a school learning management system tailored for schools in Pakistan.

## What is included
- Product vision and MVP scope
- Starter UI for admin, teacher, student, and parent workflows
- Simple local development setup

## Suggested MVP scope
- Role-based login for admin, teacher, student, and parent
- School, class, and section management
- Attendance tracking
- Lessons, assignments, quizzes, and exams
- Parent messaging and announcements
- Urdu and English friendly UI

## Run locally
```bash
cd /home/ubuntu/lms-school
python3 -m http.server 3000
```

Then open http://127.0.0.1:3000
